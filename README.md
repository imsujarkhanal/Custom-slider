# Custom Elementor Service Carousel

A custom Elementor widget built to recreate a service section carousel from a Figma design.  
This widget combines a feature image and a dynamic slider of service cards, with full control from the Elementor editor.

------------------------------------------------------------------------------------------------

## Features

- Custom Elementor widget (built with PHP - Elementor Widget API)
- Swiper.js powered carousel
- Repeater-based dynamic service cards
- Feature image + content slider layout
- Custom navigation arrows
- Fully responsive (desktop, tablet, mobile)
- Editable content directly from Elementor (no coding required)

------------------------------------------------------------------------------------------------

## Tech Stack

- PHP (WordPress + Elementor API)
- CSS (custom responsive styling)
- JavaScript (Swiper.js)
- Elementor

------------------------------------------------------------------------------------------------

## Installation

1. Download or clone this repository
2. Copy the plugin folder into:
   /wp-content/plugins/
3. Go to WordPress Dashboard → Plugins
4. Activate Custom Service Carousel
5. Open any page with Elementor

------------------------------------------------------------------------------------------------

## How to Use in Elementor

1. Open a page with Elementor
2. Search for: Custom Service Carousel
3. Drag and drop the widget into your page

### Important Layout Settings (to match design)

To achieve the correct layout from the Figma design:

- Click the page settings (gear icon)
  → Set Page Layout = Elementor Full Width

- Select the main container/section:
  - Justify Content = Center
  - Align Items = Center

------------------------------------------------------------------------------------------------

## Functionality

- Add a feature image
- Add multiple service cards using repeater

Each card supports:
- Image
- Category label
- Title
- Description
- Price and suffix
- Background color
- CTA link

- Navigate cards using custom arrow buttons

------------------------------------------------------------------------------------------------

## Responsive Behavior

- Desktop: Two-column layout (feature image + carousel)
- Tablet: Stacked layout with adjusted spacing
- Mobile: Optimized layout with proper navigation positioning
